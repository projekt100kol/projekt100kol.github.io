# Projekt 100 kôl

Statický one-page web pripravený pre GitHub Pages.

Plánovaný repozitár: `projekt100kol/projekt100kol.github.io`
Vlastná doména: `projekt100kol.sk`

## Pred zverejnením

- doplniť finálne fotografie do časovej osi,
- pripojiť formulár na odber e-mailov,
- doplniť Donio URL,
- doplniť partnerský PDF materiál,
- doplniť Instagram, e-mail, mediálne materiály a ochranu osobných údajov,
- po spustení Donia prepnúť text a cieľ hlavných CTA,
- aktualizovať počet štartov v `site-config.js`.

## Jedno miesto na bežné zmeny

Súbor `site-config.js` obsahuje aktuálny počet štartov, stav kampane a všetky externé odkazy. Pri spustení Donia stačí doplniť jeho URL a zmeniť `campaignLive` na `true`.
